# point: this file must never grow to cover a divergence nobody has read.

# KEEP THIS LIST SHORT AND ARGUED. Every entry claims mcfish may call something a

# and must name what would retire it.
#

# accepted silently -- an entry that outlives its cause turns the gate into
# decoration.

# an inlined callee to its callers.
