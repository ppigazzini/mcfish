# its reason. One group NAME per line, matched against the first field of a row
# `tools/upstream_fingerprint.sh` prints.
#
# A DIFFERS row whose group is NOT listed here fails the gate. That is the whole
# point: this file must never grow to cover a divergence nobody has read.
#
# KEEP THIS LIST SHORT AND ARGUED. Every entry claims mcfish may call something a
# different number of times than the golden, which is the opposite of what this
# port is for. A row listed here is EXEMPT from the strongest check this tree has
# on its own algorithm, so an entry needs a reason that survives being read aloud
# and must name what would retire it.
#
# A listed group that comes back EXACT is reported as retirable rather than
# accepted silently -- an entry that outlives its cause turns the gate into
# decoration.

# survives inlining and names the same call, or by teaching the tool to attribute
# an inlined callee to its callers.
movepick
