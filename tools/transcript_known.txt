# Divergences from the upstream transcript that are ACCEPTED, each with its reason.
#
# One regex per line, matched against a diff line ("<" is mcfish's, ">" is upstream's).
# A diff line matching none of these fails `./build.sh upstream-transcript`.
#
# KEEP THIS LIST SHORT AND ARGUED. Every entry is a claim that mcfish is allowed to
# differ from the golden, which is the opposite of what this port is for -- so an entry
# needs a reason that survives being read aloud, and it must name what would retire it.
# An entry that outlives its cause turns the gate into decoration, exactly as the
# normalize() filter in build.sh did for the thread info strings.

# The engine identifies itself. mcfish is a different engine and says so; matching this
# would mean claiming to be Stockfish. Never retired.
^[<>] id name

# The net replica line is now EMITTED on both sides, in the same place and once per
# replica; only the BACKING WORD differs. Upstream maps the net system-wide and says
# `Shared memory.`; mcfish holds one network in ordinary process memory and says
# `Local memory.`, which is one of upstream's own four strings and the true one here.
# Claiming `Shared memory.` would match the byte by asserting something false about the
# allocation.
#
# This entry used to accept ONLY upstream's side, because mcfish printed nothing at all
# -- so its announcement block was a line shorter than every other Stockfish's, and the
# ABSENCE was what the entry was hiding. Both sides are named now, and the pattern is
# anchored to the two backing words, so a missing line on either side fails again.
#
# RETIRE by registering the network for NUMA replication (AGENTS.md names it as open),
# after which the count follows the node count and the backing may genuinely match --
# not by widening this back to the whole line.
^[<>] info string Network replica [0-9]+: (Local|Shared) memory\.$

^[<>] info string Using [0-9]+ threads? with NUMA node thread binding
